# 📊 인공지능 수학 과제: 데이터의 경향성 파악하기 (추세선 구하기)

## 📝 과제 개요
인공지능이 데이터를 학습하여 미래를 예측하는 가장 기본적인 모델인 **'선형 회귀(Linear Regression)'**의 원리를 이해합니다. 주어진 실생활 데이터를 바탕으로 두 변수 간의 관계를 가장 잘 설명하는 **최적의 추세선(Trend Line)**을 직접 도출해 봅시다.

## 💾 데이터셋: 기온과 아이스크림 판매량

| 기온 (X, °C) | 판매량 (Y, 개) |
| :---: | :---: |
| 25 | 40 |
| 27 | 55 |
| 28 | 60 |
| 30 | 75 |
| 32 | 85 |
| 33 | 90 |
| 35 | 110 |

## 🎯 수행 과제

1. **데이터 시각화**: 주어진 데이터를 좌표평면 위에 **산점도(Scatter Plot)**로 나타내시오.
2. **추세선 도출**: 오차를 최소화하는 1차 함수 $y = ax + b$의 기울기($a$)와 y절편($b$)을 계산하시오.
   > 💡 *Hint: 수업 시간에 배운 최소제곱법 원리를 적용하거나 엑셀, 파이썬을 활용해도 좋습니다.*
3. **예측 모델링**: 도출한 추세선 방정식을 바탕으로, 기온이 **38°C**일 때의 예상 아이스크림 판매량을 예측하고 그 논리적 근거를 서술하시오.
